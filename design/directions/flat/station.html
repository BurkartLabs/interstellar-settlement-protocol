SOL-STATION-001 // SOL

Earth Station Prime

The principal orbital installation above Earth. Houses the primary offices of the Interstellar Settlement Authority and the major regulatory institutions governing colonization, commerce, and security across the Sol system. All new corporations registered under the ISP framework maintain a mandatory operational presence here.

Authority & Regulatory Offices

Government bodies, regulatory agencies, and institutional services present at this station. Access is open to all registered corporations.

STA

Orbital Executive Suites

Licensed executive office suites for corporate operations within the station. Leasing a suite establishes a formal registered presence at this location, enabling your corporation to recruit personnel and engage with the station's institutional services.

The suites are functional — climate-regulated, encrypted uplink, standard executive clearance. The prestige is in the address.

ISA

ISA Claims & Leases Division

The operational arm of the ISA responsible for processing all mining lease applications, territorial claim filings, and extraction rights across registered systems.

Queue a claim, file your survey data, and wait. The Division processes thousands of applications per cycle.

EA

Earth Assembly

The overarching governing body of humanity's settled territories. Issues executive mandates, ratifies inter-system treaties, and sets the legislative framework within which all ISA regulation operates.

Design notes — the Flat direction

One self-contained mockup, per Decision AB#1764 (the Board's answer: one direction, not three). This section is the whole proposal in words; the screen above is the same proposal in pixels.

Type system

  • Inter only. Weight (400/500/600/700) and size do the hierarchy, not a second family. The one exception is the sidebar's "ISP" wordmark, set in Orbitron — the logo mark, nothing else.
  • Tabular numerals (font-variant-numeric: tabular-nums, the .num class above) on every numeric value: Level, Employees, Building Slots, Fleet Cap, the extractor's Tier.

"Surface step" pairs are judged against the >= 1.2:1 target this direction sets for depth-by-luminance rather than the AA text thresholds, which don't apply to fills; every text/background pair above is judged against WCAG 2.1 AA (4.5:1 normal text) or better.

Cyan discipline

One primary control per screen (here: the Enter button on Orbital Executive Suites, the office a new corporation actually needs first) plus the active tab/nav item. Every other button, badge and card border uses the surface and border tokens. No box-shadow or text-shadow is used decoratively anywhere in this file — the mobile tab bar's active state uses a 1px inset outline (box-shadow: inset 0 0 0 1px, zero blur radius), which is a border, not a glow.

References

  • EVE Online's Photon UI (2022 redesign) — solved density-without-clutter by reskinning components and changing the type family rather than adding chrome; the model for "flat, dense, still legible."
  • Frostpunk — single-accent restraint: one signal colour reserved for what the player must act on, everything else desaturated.
  • Linear and Geist (Vercel) — type and spacing rhythm on a dark surface; both use one family, weight-led hierarchy, and tabular figures in data-dense views.
  • Radix Colors — the reference for building an accessible dark scale as discrete numbered steps rather than picking shades by eye; this palette's surface-1/2/3 ladder follows that shape.
